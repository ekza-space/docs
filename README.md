# Ekza Space Docs

Docusaurus documentation project for Ekza Space, the Solana-native ownership
layer for portable 3D assets, avatars, and virtual spaces.

## Commands

```bash
pnpm install
pnpm start
pnpm run build
pnpm run typecheck
```

## Source Protocol Repositories

## Deployment

The site is live at <https://docs.ekza.io>. Vercel builds and publishes every push to
`main`; other branches get a preview deployment. There is no manual deploy step.
