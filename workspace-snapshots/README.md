# Umbrella workspace snapshots

The Ekza umbrella directory is not a Git repository. These dated, unmodified
snapshots preserve its architecture, migration plan and ADRs alongside the public
documentation. They are historical records, not a second editable source of truth.
Relative links and checkout paths retain their original umbrella-workspace meaning.
`SHA256SUMS.json` records the source content hashes.

The 2026-09-21 snapshot accompanies `feature/space-account-migration` across Core,
TypeScript SDK, Rust server, Registry, Rust SDK and this documentation repository.
It describes implementation and rollout prerequisites, not a production deployment.
